# Book Recommendation System + AI Reading Assistant

A data engineering project mapped to a real Data Engineer job description — PySpark, Delta Lake, Scikit-learn and a Claude-powered AI assistant, built on the goodbooks-10k dataset.

## Progress

- Sprint 1: ETL pipeline in Databricks (PySpark + Delta Lake) — books, ratings, and book_tags tables built and cleaned
